/ FAQ

Domande ricorrenti.

Quanto costa un'app?

Web app MVP (3-5 funzionalità core): €15.000-€35.000. Native app iOS+Android base: €25.000-€60.000. App complessa (multi-tenant, payments, AI): da €60.000. Always retainer post-launch.

Quanto tempo serve?

MVP web app: 8-12 settimane. Native app: 12-20 settimane. App complesse multi-funzionalità: 4-9 mesi. Sempre con sprint settimanali e demo continue.

Quale tech stack usate?

Web: Next.js 14, React, TypeScript, Postgres, Redis, Vercel. Mobile: React Native (cross-platform), Swift (iOS native), Kotlin (Android native). Backend: Node.js, Python (FastAPI), Postgres.

Includete il design?

Sì, sempre. UX research, wireframe, design system, prototipo Figma. Design pensato come parte integrante del prodotto, non come decorazione.

Cosa succede dopo il lancio?

Pacchetto retainer mensile (€1.500-€6.000/mese) per maintenance, hot-fix, nuove feature, ottimizzazione performance. Contratto rinnovabile.

Lavorate solo con startup tech?

No. Tantissimi nostri progetti sono per brand consumer che vogliono un'app loyalty, e-commerce custom, B2B platform per gestire clienti interni.

Il codice è mio?

Sì, sempre. Repository GitHub trasferito al cliente al delivery. Documentazione tecnica completa. Puoi continuare con altri sviluppatori quando vuoi.
